A Retrospektual View — Starter Site

FILES
- index.html: main umbrella homepage
- css/style.css: all homepage styling
- js/main.js: navigation + header behavior
- studio/index.html: Joe's House Music Studio placeholder page
- film/index.html: Joe FilmedIT placeholder page

HOW TO PREVIEW
Open index.html in your browser.

HOW TO DEPLOY TO CLOUDFLARE PAGES
1. Create a GitHub repository.
2. Upload the entire contents of this folder.
3. In Cloudflare Pages, connect the repository.
4. Use no build command.
5. Set output directory to the repository root.
6. Deploy.
7. Connect aretrospektualview.com as the custom domain.

IMPORTANT
The homepage currently uses abstract CSS backgrounds so it works immediately
without image files. Replace the studio and film card backgrounds later with
your own production photos, and replace the hero background with your chosen
photo or video.
